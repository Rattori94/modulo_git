# Módulo Git

Esse repositório não é um projeto com código funcional — é onde eu treinei os comandos básicos do Git na prática, durante o módulo do curso que ensina controle de versão. Tem arquivos bem simples e propositalmente bobos (tipo `arquivo.txt`, `github.txt`, `new_file.txt`), cada um criado pra testar uma coisa diferente: um commit novo, um arquivo simulando algo vindo de um repositório remoto, um `conflito.txt` pra forçar e resolver um conflito de merge, e um `changelog.md` seguindo o formato do Keep a Changelog pra registrar as mudanças como se fosse um projeto de verdade.

O que ficou disso foi entender Git além do "salvar e mandar pro GitHub": como o histórico de commits realmente funciona, o que acontece quando duas versões de um arquivo colidem e como resolver isso sem entrar em pânico, a diferença entre trabalhar local e sincronizar com o remoto, e por que manter um changelog organizado ajuda a entender a evolução de um projeto depois. É meio chato de explicar porque não tem uma "tela" pra mostrar, mas foi a base de tudo que uso hoje em qualquer outro repositório.

**Tecnologias e ferramentas:** Git, GitHub, Markdown.
